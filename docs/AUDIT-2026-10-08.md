# Launch-readiness audit — canyonstateaz.com — 2026-10-08

Eight generic audit checklists were run against this site. Three do not apply
(App Store, Auth, Payments: no mobile app, no accounts, no payments). This report
covers the five that do. Every item below was checked against the actual code,
config, DNS or live site; nothing is assumed.

**Stack:** React 19 + Vite 7 static site on Netlify (auto-deploy from `main`),
Puppeteer prerender of every route, one serverless function
(`netlify/functions/contact.js` → Resend email), Google Tag Manager
(GTM-NDBJ277C → GA4 + Google Ads). No database, no logins, no uploads, no
user-generated content.

Legend: **PASS** / **FAIL → fixed** / **PARTIAL** / **N/A** / **HUMAN** (needs an
account or decision we don't have).

## 5. Instructions and decisions for the owners

**A. Email (Andrew's team, DNS at Microsoft/Azure DNS)**
1. Turn on DKIM for Microsoft 365 outbound mail: Microsoft 365 Defender → Email authentication → DKIM → canyonstateaz.com → it will show two CNAMEs (`selector1._domainkey`, `selector2._domainkey`) → add them in DNS → Enable.
2. Tighten DMARC. Change the `_dmarc.canyonstateaz.com` TXT record from
   `v=DMARC1; p=none;` to
   `v=DMARC1; p=quarantine; pct=100; rua=mailto:office@canyonstateaz.com; adkim=r; aspf=r`
   Do step 1 first; otherwise office mail could be quarantined.
   (Resend is already correctly set up: DKIM + SPF + return path on `send.canyonstateaz.com`.)

**B. Contact-form bot protection (Brandon or Andrew, 10 minutes)**
1. Cloudflare dashboard (free account is fine; the domain does not need to be on Cloudflare) → Turnstile → Add widget → hostname `canyonstateaz.com` → mode "Managed" → copy the Site Key and Secret Key.
2. Netlify → Site configuration → Environment variables → add
   `VITE_TURNSTILE_SITE_KEY` = site key, `TURNSTILE_SECRET_KEY` = secret key.
3. Trigger a deploy (Deploys → Trigger deploy). The widget appears above the Send button; submissions without a valid token are rejected. Until the keys exist, the form behaves exactly as before.

**C. A tracking tag the owners should know about**
The GTM container tries to load a script from `pxl.greenbergenterprises.com`; the site's security policy blocks it (visible as a console error). Decide: if this pixel is wanted (an agency/SEO tracker?), tell me and I will allow that host in the CSP; if not, remove the tag in GTM. Doing nothing is also safe; it just stays blocked.

**D. Privacy policy wording (for Andrew to approve, not yet changed)**
Under "Third-Party Services", replace the Google Analytics line with:
"Google Tag Manager, Google Analytics and Google Ads — to measure website traffic and the results of our advertising. These services set cookies (for example `_ga`, `_gcl_au`); you can block them in your browser settings."
Under "Cookies", replace "may use cookies" with "uses cookies set by the Google services above".

**E. Monitoring (Brandon, 15 minutes)**
1. Netlify → Site → Notifications → add "Deploy failed" email to pinchpointai@gmail.com.
2. UptimeRobot (free) → two HTTPS monitors: `https://canyonstateaz.com/` and `https://canyonstateaz.com/contact`, keyword "Canyon State", 5-minute interval, email alert.
3. Resend → Settings → Usage alerts → on.

**F. If the site is down (runbook)**
- Check https://www.netlifystatus.com first.
- Netlify → Deploys → pick the last good deploy → "Publish deploy" (instant rollback).
- Contact form failing but site up: Netlify → Functions → `contact` → logs; check the Resend dashboard for bounces/quota.
- Domain/DNS issues: Andrew's team (Azure DNS). Site SSL is Netlify-managed and auto-renews.

**G. Still open after this audit**
- Google Business Profile confirmation (A/HUMAN above).
- Send one real contact-form submission and confirm delivery.
- Attorney read of `/terms`.
